**Introducción**

En el presente trabajo se desarrolló un Sistema de Inventario en Python, aplicando los conceptos de Programación Orientada a Objetos (POO) y el uso de colecciones de datos. El objetivo principal fue diseñar un programa capaz de gestionar productos mediante operaciones básicas como agregar, eliminar, actualizar, buscar y mostrar información del inventario.

El sistema permite almacenar la información de los productos utilizando estructuras de datos eficientes, facilitando la organización y manipulación de los datos. Además, se implementó la persistencia de datos mediante archivos JSON, lo que permite guardar y recuperar la información del inventario cuando el programa se ejecuta nuevamente.

Este proyecto permitió aplicar conocimientos teóricos en un caso práctico, fortaleciendo el aprendizaje del lenguaje Python y la programación estructurada y orientada a objetos.

**Desarrollo**

El sistema fue desarrollado utilizando el lenguaje de programación Python y se organizó en varios archivos para mantener una estructura clara y ordenada. Se creó una clase Producto, encargada de representar cada producto del inventario con atributos como ID, nombre, cantidad y precio.

También se implementó la clase Inventario, que permite gestionar los productos mediante diferentes métodos como:

Agregar productos al inventario

Eliminar productos

Actualizar cantidad y precio

Buscar productos por nombre

Mostrar productos registrados

Guardar información en archivos JSON

Cargar información desde archivos JSON

Para el funcionamiento del sistema se utilizaron cuatro tipos de colecciones de datos:

Diccionario: Se utilizó como colección principal para almacenar los productos mediante su ID, permitiendo búsquedas rápidas y eficientes.

Lista: Se utilizó para almacenar los resultados de búsqueda de productos por nombre.

Conjunto (Set): Se utilizó para obtener los IDs únicos de los productos almacenados.

Tupla: Se utilizó para generar un resumen del inventario con el número total de productos y la cantidad total disponible.

El sistema también incluye una interfaz sencilla basada en menú que permite al usuario interactuar con el programa desde la consola. Además, se añadieron mensajes informativos y emojis para mejorar la experiencia del usuario y facilitar la comprensión de las acciones realizadas.

Este sistema cumple con los requisitos solicitados y demuestra el uso correcto de la Programación Orientada a Objetos junto con estructuras de datos en Python.

**Conclusión**

En conclusión, el desarrollo del sistema de inventario permitió comprender de manera práctica el uso de la Programación Orientada a Objetos en Python, así como la utilización de diferentes colecciones de datos para organizar la información de forma eficiente.

El programa desarrollado permite gestionar productos de manera sencilla y organizada, facilitando operaciones como la búsqueda, actualización y almacenamiento de datos. Además, el uso de archivos JSON permite mantener la información guardada para futuras ejecuciones del sistema.

Este proyecto ayudó a fortalecer los conocimientos adquiridos durante la unidad de estudio, especialmente en el manejo de clases, objetos y estructuras de datos. También permitió mejorar la lógica de programación y la organización del código.

Finalmente, se logró implementar un sistema funcional que cumple con los requerimientos establecidos, demostrando la aplicación práctica de los conceptos aprendidos en clase.
